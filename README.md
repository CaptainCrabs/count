# 记账看板 · 使用说明

个人资产负债表应用。在电脑上记账，手机可以看同一本账。数据只存在这台电脑上，不登录、不上云。

---

## 1. 第一次使用

1. 安装 [Node.js LTS](https://nodejs.org/)（若尚未安装）。
2. 打开项目文件夹，双击 **`启动记账.bat`**。
3. 等黑色窗口出现地址后，用浏览器打开：

   - 本机：http://localhost:8787/
4. 首次进入会看到欢迎页：
   - **载入演示数据**：先看效果（含近几个月流水）
   - **从空白账本开始**：只预置现金、银行卡、支付宝、微信、信用卡和常用分类

不要关闭那个黑色窗口，关掉服务就停了。

---

## 2. 重启电脑后怎么打开

双击 **`启动记账.bat`**，等窗口打印地址后再访问。

可选：双击 **`安装开机启动.bat`**，以后开机自动启动。要取消，到 Windows「启动」文件夹里删掉「开机启动记账.vbs」。

电脑休眠后，手机也会连不上。

---

## 3. 日常记账

### 记一笔

- 点右下角 **记一笔**，或按键盘 **N**
- 四种类型：
  - **支出**：选分类（餐饮、交通等）和付款账户
  - **收入**：选分类（工资等）和收款账户
  - **转账**：资产账户之间调动，净资产不变
  - **还款**：用资产还信用卡等负债，净资产不变
- 金额填好后回车即可保存
- 会记住你上次用的账户和分类

底层是复式记账：记一笔支出或收入时，资产负债表会自动保持平衡。

### 流水

查看、搜索、筛选本月记录。可以对某一笔 **复制 / 编辑 / 删除**。

### 账户与分类

- **资金账户**：现金、银行卡、支付宝、微信、基金、信用卡等，可填期初余额
- **收支分类**：工资、餐饮等
- 已有流水的账户不能删除，可改为停用

---

## 4. 看板和报表

| 页面 | 作用 |
| --- | --- |
| 总览 | 净资产、本月收支、趋势图、分类占比、账户余额 |
| 资产负债表 | 某一天的资产、负债、权益，并校验「资产 = 负债 + 权益」 |
| 月度收支 | 按月看收入、支出、结余和分类明细 |
| 存钱分析 | 储蓄率、本年累计、应急金可撑几个月、压缩某类支出能多存多少；可设每月储蓄目标 |

页面右上角可以切换月份。

---

## 5. 导入微信 / 支付宝账单（自动记账）

不会登录你的微信或支付宝。请用 **官方导出的账单文件**。

1. 打开侧栏 **导入账单**（流水页也有入口）
2. 导出账单：
   - **微信**：我 → 服务 → 钱包 → 账单 → 右上角 → 下载账单。可直接上传解压后的 **xlsx**，或未解压的 **zip**
   - **支付宝**：我的 → 账单 → 右上角 → 导出，上传 **xlsx / xls / csv**
3. 核对预览：可改账户、分类，或取消勾选不想入账的
4. 点 **导入选中的 N 笔**

说明：

- 支持 `xlsx`、`xls`、`csv`、`txt`、微信账单 `zip`
- 会按商户名猜测分类（如瑞幸→餐饮）
- 同一笔 **交易单号只会入账一次**，重复上传会跳过
- 导入后请到流水里抽查几笔

---

## 6. 备份

打开 **设置**：

- **导出备份**：下载 JSON，换电脑或清理浏览器前务必先导出
- **导入备份**：会覆盖当前账本
- **清空账本**：全部删除，不可恢复

日常数据还会同步到项目目录的 `data/ledger.json`（用「启动记账.bat」时）。

---

## 7. 用手机访问

### 家里同一 WiFi

1. 电脑运行 `启动记账.bat`
2. 看窗口里的局域网地址，例如 `http://192.168.x.x:8787/`
3. 手机浏览器打开该地址，输入 **访问码**（窗口和设置页都有）

本机浏览器一般不用填访问码。

若连不上：确认手机和电脑在同一 WiFi；Windows 防火墙若弹出，允许 Node.js 访问专用网络。

### 外出时（公网）

1. 电脑运行 **`公网分享.bat`**（或先启动记账再运行它）
2. 窗口会出现 `https://....trycloudflare.com` 一类地址
3. 手机打开该地址，输入访问码

注意：

- 这是把账本临时暴露到公网，访问码不要发给别人
- 电脑必须保持开机、联网、不要休眠
- 每次重新分享，网址可能都会变
- 隧道断开后需要再运行一次

## 8. 开发者命令（可选）

```bash
npm install
npm run dev      # 开发预览，默认 http://localhost:5173/
npm run build    # 构建网页
npm run start    # 本机服务器，http://localhost:8787/
npm run share    # 启动服务并开通公网隧道
```

## 9. 常见问题

**刷新后数据还在吗？**  
在。存在浏览器和电脑上的 `data/ledger.json`。仍建议定期导出备份。

**转账后净资产为什么没变？**  
转账只是钱从左边口袋到右边口袋。还款会同时减少资产和负债，净资产也不变。

**导入账单识别不到表头？**  
请用官方导出文件，不要改列名。微信若下载的是压缩包，可直接上传 zip，或解压后上传里面的 xlsx/csv。

**为什么不能自动读取微信、支付宝？**  
它们不提供个人账单接口。只能使用官方导出文件导入，这是安全且稳定的做法。

**访问码在哪？**  
启动窗口会打印；电脑本机打开后，设置页「手机访问」里也能看到。
